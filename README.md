# GameVault 游戏介绍站

一个纯静态游戏介绍网站，包含游戏目录、攻略、玩家评分、搜索筛选和详情弹窗。

## 文件结构

- `index.html`：页面结构
- `styles.css`：页面样式和响应式布局
- `script.js`：游戏数据、筛选、评分和详情弹窗
- `assets/`：游戏封面图

## 本地预览

直接用浏览器打开 `index.html`。

## 发布到 GitHub Pages

1. 进入仓库 `Settings` -> `Pages`。
2. Source 选择 `Deploy from a branch`。
3. Branch 选择 `main`，目录选择 `/root`，保存。
4. 等待 GitHub Pages 构建完成后访问生成的网址。
